# Insight Navigator

Prompt Elite para o Lovable — Sistema DRE + Dashboard Executivo

Objetivo: Criar um sistema profissional de gestão financeira e DRE (Demonstrativo de Resultado do Exercício), substituindo planilhas Excel por uma plataforma moderna, visual e inteligente, inspirada em dashboards escuros premium semelhantes ao layout deste exemplo: painéis corporativos com gráficos e KPIs de alta qualidade.

SYSTEM PROMPT

Crie um sistema SaaS profissional chamado Finance Vision Pro, focado em gestão financeira empresarial, DRE e Business Intelligence.

O design deve ser extremamente moderno, elegante e corporativo, inspirado em dashboards premium com tema escuro (Dark Mode), utilizando:
